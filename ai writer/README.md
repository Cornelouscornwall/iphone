# Chromebook VPN Portal

This app is optimized for fast startup and clean browser opening on a Chromebook. It starts a local server and opens the VPN portal automatically so you do not need to manually type anything in the browser.

## Run it

From this folder:

```bash
chmod +x start.sh
./start.sh
```

The app will open:

```text
http://localhost:8000/
```

## Notes

This is a lightweight, self-contained local VPN dashboard designed for quick access on ChromeOS devices.
